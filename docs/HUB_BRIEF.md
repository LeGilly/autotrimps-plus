# AutoTrimps Plus: brief for the hub (legilly.com)

Facts to describe this project on the hub. Check `CHANGELOG.md` for the current version before quoting it.

## What it is

- A mod for **Trimps on Steam** (5.10.1) that plays the game for you: AutoTrimps (SadAugust's fork, kept
  unmodified inside) plus "Plus" features that take over the decisions AutoTrimps leaves to the player.
  The goal is a game that runs hands-off from a new save.
- **Not a website and not on the Steam Workshop**: a local mod, installed by unzipping a release into
  `…\steamapps\common\Trimps\mods\`. Like Frozen Cookies Plus, the hub can only link to the repository,
  the README and the releases. It belongs under **Idle game optimisers**.

## Links

- Releases (zip per version, notes from the changelog): https://github.com/LeGilly/autotrimps-plus/releases

## Features worth listing (as of 0.1.0)

- Runs AutoTrimps offline from the mod folder, nothing downloaded at launch.
- Planned (not there yet, don't list as done): automatic portal and challenge choice, void and unique maps,
  Masteries, settings that update themselves with progress, then an achievement hunter.
